    Where do I get these files?

    Browser bookmarks
    In Chrome, Edge, Firefox, or Safari open the bookmark manager and choose Export bookmarks — you get one .html file. Drop it here. Chrome users can also drop the raw Bookmarks file from the Chrome profile folder.
    Facebook & Messenger
    On Facebook go to Settings & privacy → Download your information, pick Messages and/or Saved items, and set the format to JSON (not HTML). Facebook emails you a ZIP; unzip it, then drop the message_1.json files (one per conversation, under messages/inbox/…) and your_saved_items.json here. You can drop many files at once. Text in any language is fixed automatically — Facebook's export garbles non-English characters, and Shoebox repairs them.
    X (Twitter)
    Two options. Archive: request Settings → Your account → Download an archive of your data, unzip, and drop like.js or tweets.js from the data folder. Bookmarks: X only exposes bookmarks through its paid API — if you (or a developer friend) fetch GET /2/users/:id/bookmarks, drop the JSON response here and it's understood.

    shoebox_ has no server, no accounts, and no analytics. The page's security policy forbids all network connections, so your data cannot be sent anywhere — you can verify this in your browser's network tab. Nothing is fetched per-item either (not even favicons), so the sites you saved never learn you're organizing them. Dead-link checking and live X sync are deliberately left out for now: both would require network access. Source code is one readable HTML file — audit it.
