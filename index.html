    Where do I get these files?

    Browser bookmarks
    In Chrome, Edge, Firefox, or Safari open the bookmark manager and choose Export bookmarks — you get one .html file. Drop it here. Chrome users can also drop the raw Bookmarks file from the Chrome profile folder.
    Facebook & Messenger
    On Facebook go to Settings & privacy → Download your information, pick Messages and/or Saved items, and set the format to JSON (not HTML). Facebook emails you a ZIP; unzip it, then drop the message_1.json files (one per conversation, under messages/inbox/…) and your_saved_items.json here. You can drop many files at once. Text in any language is fixed automatically — Facebook's export garbles non-English characters, and Bokmark repairs them.
    X (Twitter)
    Two options. Archive: request Settings → Your account → Download an archive of your data, unzip, and drop like.js or tweets.js from the data folder. Bookmarks: X only exposes bookmarks through its paid API — if you (or a developer friend) fetch GET /2/users/:id/bookmarks, drop the JSON response here and it's understood.

    bokmark_ has no accounts and no analytics. Importing, filtering, sorting into tables and exporting all happen in your browser; what you import is stored only on your device. Its security policy lets the page contact just four services, each tied to one feature: cdnjs.cloudflare.com (spreadsheet library, on load), huggingface.co / cdn.jsdelivr.net (the private on-device model, only if you choose Private sort), the Bokmark sorting service (only if you choose Smart sort — it receives item titles, domains and types, forwards them to Claude for folder names, and stores none of it; URLs, people's names, chat names and message bodies are never sent), and api.anthropic.com (only if you supply your own key). No favicons or trackers are fetched, so the sites you saved never learn you're organizing them. Source is one readable HTML file, and the service is one small readable Worker — audit both.
